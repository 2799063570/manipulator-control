## 题目一：有序数组的两数之和

给定一个**按升序排列**的整数数组 `numbers` 和一个目标值 `target`，请在数组中找出两个数，使它们的和等于 `target`，并返回这两个数的下标。

### 方法一：暴力枚举

依次枚举所有不同的元素组合，找到和为 `target` 的一对即可返回。

```cpp
vector<int> getTwoIndex(const vector<int>& nums, int target)
{
    for (int i = 0, size = nums.size(); i < size - 1; ++i)
    {
        for (int j = i + 1; j < size; ++j)
        {
            if (nums[i] + nums[j] == target)
                return {i, j};
        }
    }
    return {};
}
```

该方法实现直接，但存在两层循环：时间复杂度为 O(n²)，额外空间复杂度为 O(1)。

### 方法二：首尾双指针

有序数组可以利用单调性缩小搜索范围。令左指针从数组开头出发，右指针从数组末尾出发：

- 若两数之和等于 `target`，直接返回下标；
- 若和大于 `target`，右指针左移，使和变小；
- 若和小于 `target`，左指针右移，使和变大；
- 当两个指针相遇时，说明不存在满足条件的组合。

```cpp
vector<int> getTwoIndexTwoPointer(const vector<int>& nums, int target)
{
    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    while (left < right)
    {
        const int sum = nums[left] + nums[right];
        if (sum == target)
            return {left, right};
        if (sum > target)
            --right;
        else
            ++left;
    }
    return {};
}
```

该方法中每个指针最多遍历数组一次，时间复杂度为 O(n)，额外空间复杂度为 O(1)。实现时应注意：题目要求的下标是从 0 还是从 1 开始；同时可将两数之和保存到 `sum`，避免重复计算。

### 方法三：哈希表

遍历数组时，查询目标差值 `target - nums[i]` 是否已经出现过；若出现过，则当前元素与该差值组成答案。

```cpp
vector<int> getTwoIndexHash(const vector<int>& nums, int target)
{
    unordered_map<int, int> indexByValue;

    for (int i = 0, size = nums.size(); i < size; ++i)
    {
        const int other = target - nums[i];
        auto it = indexByValue.find(other);
        if (it != indexByValue.end())
            return {it->second, i};

        indexByValue[nums[i]] = i;
    }
    return {};
}
```

哈希表的思路与前一天的“两数之和”一致：平均时间复杂度为 O(n)，额外空间复杂度为 O(n)。对于本题，双指针方法能进一步利用“数组有序”这一条件，将额外空间降为 O(1)。

## 题目二：移除元素

给定数组 `nums` 和一个值 `val`，要求**原地删除**数组中所有等于 `val` 的元素，并返回删除后数组的新长度。返回长度后的元素内容不作要求。

### 方法一：快慢指针

慢指针始终指向下一个可写入的位置；快指针负责扫描整个数组。每当快指针找到一个不等于 `val` 的元素，就把它写入慢指针的位置，然后移动慢指针。
**慢指针维护不删的元素，快指针去查找要删除的元素**

```cpp
int removeElementFastSlow(vector<int>& nums, int val)
{
    int slow = 0;

    for (int fast = 0; fast < static_cast<int>(nums.size()); ++fast)
    {
        if (nums[fast] != val)
            nums[slow++] = nums[fast];
    }
    return slow;
}
```

时间复杂度为 O(n)，额外空间复杂度为 O(1)。该方法会保留未删除元素的相对顺序。

### 方法二：首尾指针

若不要求保留元素顺序，可以用数组末尾的有效元素覆盖前方待删除的位置。这样在待删除元素较少时，写入次数可能更少。

```cpp
int removeElementStartEnd(vector<int>& nums, int val)
{
    int start = 0;
    int end = static_cast<int>(nums.size());

    while (start < end)
    {
        if (nums[start] == val)
            nums[start] = nums[--end];
        else
            ++start;
    }
    return end;
}
```

时间复杂度为 O(n)，额外空间复杂度为 O(1)。需要特别注意循环边界：`end` 表示当前有效区间的右边界（开区间），替换后不应立刻移动 `start`，因为换入的元素还需要重新检查。该方法不保证元素原有顺序。

### 方法三：创建新数组

遍历原数组，将所有不等于 `val` 的元素写入新数组，再将结果赋回原数组。

```cpp
int removeElementWithVector(vector<int>& nums, int val)
{
    vector<int> result;
    for (int value : nums)
    {
        if (value != val)
            result.push_back(value);
    }
    nums = result;
    return static_cast<int>(result.size());
}
```

该方法易于理解，但时间复杂度为 O(n)，额外空间复杂度也为 O(n)，不满足严格的原地操作要求。

## C++：指针、引用与空指针

- 指针是保存内存地址的变量，可以通过解引用操作访问或修改该地址处的对象。
- 引用是已有变量的别名；初始化后会一直绑定同一个对象，使用时与原变量无异。
- 空指针不指向任何有效对象。使用前应先判断，不能直接解引用。

```cpp
int a = 9;

a = 10;       // 通过变量本身修改

int& b = a;
b = 89;       // 通过引用修改

int* c = &a;
*c = 23;      // 通过指针修改
```

## ROS2：Publisher / Subscriber 验证

Publisher 负责向话题发布消息，Subscriber 负责订阅话题并在收到消息时执行回调。下面是核心接口的简化示例：

```cpp
auto pub = this->create_publisher<MsgType>("topic", 10);

auto sub = this->create_subscription<MsgType>(
    "topic", 10,
    [this](const MsgType& msg)
    {
        this->callback(msg);
    });
```

运行节点后，可以使用以下命令直接查看话题消息，以确认发布端是否正常工作：

```bash
ros2 topic echo <topic>
```
