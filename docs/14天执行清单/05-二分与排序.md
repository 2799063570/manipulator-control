## 二分查找：先确定区间与不变量

二分查找适用于**有序**且可以根据比较结果排除一半区间的问题。写代码前要先确定：

- 搜索区间是左闭右闭 `[left, right]`，还是左闭右开 `[left, right)`；
- 循环条件与区间定义是否一致；
- `target` 不存在时需要返回什么边界。

下面使用左闭右闭区间。循环不变量是：若 `target` 存在，它一定在当前 `[left, right]` 中。

```cpp
int binarySearch(const vector<int>& nums, int target)
{
    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    while (left <= right)
    {
        const int mid = left + (right - left) / 2;
        if (nums[mid] == target)
            return mid;
        if (nums[mid] < target)
            left = mid + 1;
        else
            right = mid - 1;
    }
    return -1;
}
```

`left + (right - left) / 2` 可以避免 `left + right` 在大整数范围内相加溢出。该算法的时间复杂度为 O(log n)，额外空间复杂度为 O(1)。

## 题目二：搜索插入位置（LeetCode 35）

给定升序数组 `nums` 和目标值 `target`：若 `target` 存在，返回其下标；否则返回它应该插入的位置，且插入后仍保持升序。

题目只要求**返回位置**，不要求也不应在函数中修改 `nums`。

### 错误记录（保留）

下面是原始写法，保留用于复盘：`return m` 位于循环内部，无论当前元素与目标值的关系如何，第一次循环就会提前返回；同时 `nums.insert(...)` 改变了输入数组，也不符合本题只返回插入位置的要求。

```cpp
int searchInsertIndex(vector<int>& nums, int target)
{
    int l = -1, r = nums.size();
    while (r - l > 1)
    {
        int m = (l+r)/2;
        if (nums[m] < target) l = m;
        else if (nums[m] > target) r = m;
        return m;
    }
    nums.insert(nums.begin() + r, target);
    return r;
}
```

最小反例：`nums = [1, 3, 5]`，`target = 5`。第一次计算 `m = 1` 后，程序直接返回 `1`，正确答案应为 `2`。

### 复盘与正确实现：寻找第一个大于等于 `target` 的位置

搜索插入位置本质上是寻找第一个满足 `nums[index] >= target` 的下标，也称 lower bound。这里使用哨兵区间：`left` 始终位于答案左侧，`right` 始终位于答案位置或答案右侧；最终 `right` 即答案。

```cpp
int searchInsertIndex(const vector<int>& nums, int target)
{
    int left = -1;
    int right = static_cast<int>(nums.size());

    while (right - left > 1)
    {
        const int mid = left + (right - left) / 2;
        if (nums[mid] < target)
            left = mid;
        else
            right = mid;
    }
    return right;
}
```

当数组包含重复值时，该写法会返回最左侧的相等元素。例如 `nums = [1, 3, 3, 3, 5]`、`target = 3` 时，返回 `1`。

## 进阶一：第一个大于等于 `target` 的位置

对于 `nums = [1, 2, 4, 4, 4, 7, 9]`，寻找第一个 `>= target` 的位置。

### 错误记录（保留）

原始代码在相等时返回 `m + 1`，这会跳过当前命中的元素，因此不是“第一个大于等于”的位置。`target = 4` 时，可能返回中间某个 `4` 后的位置，而非下标 `2`。

```cpp
int getGeaterIndex(const vector<int>& nums, int target)
{
    int l = -1, r = nums.size();
    while (r - l > 1)
    {
        int m = (l+r)/2;
        if (nums[m] < target) l = m;
        else if (nums[m] > target) r = m;
        else return m+1;
    }
    return r;
}
```

### 复盘与正确实现

相等时也要继续向左收缩，所以条件可直接合并为：小于目标值时移动左边界，否则移动右边界。

```cpp
int firstGreaterEqual(const vector<int>& nums, int target)
{
    int left = -1;
    int right = static_cast<int>(nums.size());

    while (right - left > 1)
    {
        const int mid = left + (right - left) / 2;
        if (nums[mid] < target)
            left = mid;
        else
            right = mid;
    }
    return right;  // 可能等于 nums.size()，表示不存在这样的元素
}
```

## 进阶二：最后一个小于等于 `target` 的位置

对于 `nums = [1, 2, 4, 4, 4, 7, 9]`，`target = 4` 时应返回下标 `4`。

### 错误记录（保留）

原始写法在遇到相等元素时立即返回 `m`，无法保证这个 `m` 是最右侧的相等元素。

```cpp
int getSmallIndex(const vector<int>& nums, int target)
{
    int l = -1, r = nums.size();
    while (r - l > 1)
    {
        int m = (l+r)/2;
        if (nums[m] < target) l = m;
        else if (nums[m] > target) r = m;
        else return m;
    }
    return l;
}
```

最小反例：`nums = [4, 4, 4]`，`target = 4`。中点是 `1`，但正确答案是 `2`。

### 复盘与正确实现

要找最右边界，相等时也要继续向右收缩。因此当 `nums[mid] <= target` 时移动左边界，最后的 `left` 就是答案。

```cpp
int lastLessEqual(const vector<int>& nums, int target)
{
    int left = -1;
    int right = static_cast<int>(nums.size());

    while (right - left > 1)
    {
        const int mid = left + (right - left) / 2;
        if (nums[mid] <= target)
            left = mid;
        else
            right = mid;
    }
    return left;  // 可能为 -1，表示不存在这样的元素
}
```

## C++：`std::sort`、比较器与 lambda

`std::sort` 位于 `<algorithm>`，用于对随机访问迭代器范围排序。标准保证其比较次数为 O(n log n)；具体实现由标准库决定，常见实现会采用内省排序等策略。

常见形式为：

```cpp
std::sort(first, last, comparator);
```

比较器必须定义严格弱序：当它返回 `true` 时，表示第一个元素应排在第二个元素之前。lambda 的基本形式为：

```cpp
[capture](parameters) -> return_type
{
    // 函数体
}
```

返回类型通常可以由编译器推导；比较 `pair` 时使用常量引用可避免不必要的复制。

```cpp
sort(nums2.begin(), nums2.end(),
     [](const pair<int, int>& a, const pair<int, int>& b)
     {
         if (a.second != b.second)
             return a.second < b.second;
         return a.first < b.first;
     });
```

上例先按第二个字段升序排序；第二个字段相等时，再按第一个字段升序排序。

## Linux：进程查看与管理

Linux 中每个运行的程序实例都是进程，并由 PID 唯一标识。ROS2 节点退出不完整时，残留进程可能继续占用资源、端口或发布旧话题，因此排查时应先确认进程身份，再选择合适的结束方式。

| 目的 | 命令 | 说明 |
| --- | --- | --- |
| 查看进程快照 | `ps aux` | 查看系统中的进程信息，包括 PID。 |
| 按关键字查找 | `pgrep -af ros` | 比 `ps aux \| grep ros` 更不易把 `grep` 本身误匹配进结果。 |
| 实时查看资源 | `top` / `htop` | 观察 CPU、内存和进程状态。 |
| 正常结束进程 | `kill PID` | 默认发送 `SIGTERM`，允许程序清理资源后退出。 |
| 强制结束进程 | `kill -9 PID` | 发送不可捕获的 `SIGKILL`；仅在正常结束无效时使用。 |
| 按名称结束 | `killall 名称` | 会影响所有同名进程，使用前应确认范围。 |
| 查看进程树 | `pstree` | 查看父子进程关系。 |
| 查看端口 | `ss -ltnp` | 查看监听 TCP 端口及对应进程。 |

建议排查顺序：先用 `ps`、`pgrep` 或 `top` 确认 PID 和命令行，再使用 `kill PID`；只有进程不响应时，才考虑 `kill -9 PID`。

## ROS2：参数与 launch

参数用于在运行时配置节点行为，使程序能够适配不同环境而无需修改源码、重新编译。例如，可把发布频率声明为参数并读取：

```cpp
this->declare_parameter<double>("publish_rate", 10.0);
const double publish_rate =
    this->get_parameter("publish_rate").as_double();
```

ROS2 参数 YAML 使用 `ros__parameters` 作为固定键：

```yaml
publisher_node:
  ros__parameters:
    publish_rate: 10.0
    topic_name: /status
```

也可以用 `/**` 向多个节点提供通用参数：

```yaml
/**:
  ros__parameters:
    publish_rate: 10.0
```

launch 文件用于自动启动多个节点，并可统一配置参数、命名空间、话题重映射和运行环境。参数文件通常通过 launch 的 `parameters=["/path/to/params.yaml"]` 传给节点；更改 YAML 中的 `publish_rate` 后重新启动 launch，即可改变频率而不改动代码。
