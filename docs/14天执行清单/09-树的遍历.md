unique_ptr表示唯一所有权，不能复制，只能移动，适用于明确单一拥有者的资源管理；shared_ptr通过引用计数实现多个对象共享所有权；weak_ptr是不参与引用计数的弱引用，用于观察shared_ptr管理的对象，并解决shared_ptr循环引用导致的内存泄漏问题。
- `unique_ptr` 的所有权转移
`unique_ptr` 表示独占所有权，不能复制，只能通过 `std::move()` 转移所有权，转移后原指针变为空。
- `shared_ptr` 的引用计数
`shared_ptr` 通过引用计数管理对象生命周期，多个 shared_ptr 可以共同拥有同一个对象，当强引用计数变为0时自动释放对象。
- `weak_ptr::lock()`
`weak_ptr` 是 shared_ptr 的弱引用，不增加引用计数，通过 `lock()` 可以安全获取一个 shared_ptr，如果对象已经释放则返回空。
- 循环引用为什么导致泄漏
循环引用是因为多个 shared_ptr 相互持有，导致引用计数始终大于0，对象无法析构，造成内存泄漏，通常使用 weak_ptr 打破循环。

- OS：条件变量与生产者消费者。
生产者消费者模型通过一个共享缓冲区连接生产线程和消费线程。生产者负责产生数据并放入缓冲区，消费者负责从缓冲区取出数据。为了避免数据竞争，需要使用 mutex 保证访问安全，并使用 condition_variable 让消费者在无数据时阻塞，有数据时被唤醒。

条件变量是一种线程同步机制，用于实现线程之间基于条件的等待和通知。线程调用 wait() 在条件不满足时进入阻塞状态，并释放互斥锁；当其他线程改变共享状态后，通过 notify_one() 或 notify_all() 唤醒等待线程。

```cpp
#include<iostream>
#include<queue>
#include<thread>
#include<mutex>
#include<condition_variable>


using namespace std;


queue<int> q;
mutex mtx;
condition_variable cv;



void producer()
{
    for(int i=0;i<10;i++)
    {
        {
            lock_guard<mutex> lock(mtx);
            q.push(i);
        }
        cout<<"produce "<<i<<endl;
        cv.notify_one();
    }
}

void consumer()
{
    while(true)
    {
        unique_lock<mutex> lock(mtx);
        cv.wait(lock,[]{
            return !q.empty();
        });
        int value=q.front();
        q.pop();
        cout<<"consume "<<value<<endl;

        if(value==9)
            break;
    }
}

int main()
{

    thread t1(producer);
    thread t2(consumer);
    t1.join();
    t2.join();
}
```
