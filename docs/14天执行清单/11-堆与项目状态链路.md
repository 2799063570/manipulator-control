# 一、数组中的第 K 个最大元素

## 1. 问题描述

给定数组：

```
nums = [3,2,1,5,6,4]
```

要求：

找出第 k 大的元素。

有两个方法，一个是利用排序算法，对数组中的元素进行从大到小的排序
另一种是利用线性模拟树，可以利用最小堆
我们将最大的几个元素存储到堆中，不断的将堆中的最小元素弹出
```cpp
int getKNum(const vector<int>& nums, int k)
{
    priority_queue<int, vector<int>, greater<int>> q;
    for (int n : nums)
    {
        q.push(n);
        if (q.size() > k) q.pop();
    }
    return q.top();
}
```
