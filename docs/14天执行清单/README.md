# 14 天基础补齐打卡目录

本目录是 [[33-基础补齐-14天执行清单]] 的每日执行与复盘区。每天只完成当天文件，不补写长篇总结；算法题必须填写耗时、复杂度、边界测试和错误根因。

## 使用规则

1. 开始前在当天页面填写日期和准备练习的题目。
2. 每道算法题限时完成；结束后立即填写固定格式，不要等到周末。
3. 每天保留一条 C++/Linux 记录和一条 ROS/项目记录；可贴命令、现象或截图路径。
4. 第 7、14 天完成模拟与周复盘后，再进入下一页。
