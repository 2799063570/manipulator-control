# 项目实施清单

## 第 0 周：建立基线

- [ ] 在 Linux 成功构建 `robot_control_ros2`。
- [ ] 启动现有二维臂 Gazebo + MoveIt demo。
- [ ] 保存 `ros2 node list`、controller 列表、TF 图截图。
- [ ] 为每个工作区写清 ROS 发行版与依赖锁定说明。

## 第 1–2 周：二维机械臂闭环

- [ ] 在 RViz 验证 URDF、joint limit 和 TF。
- [ ] 在 Gazebo 以 action 执行至少 10 次关节目标。
- [ ] 验证 MoveIt 规划、碰撞检测与取消 action。
- [ ] 加入工作台、方块、夹爪，并完成一次抓放演示。
- [ ] 记录随机规划成功率和执行误差。

## 第 3–4 周：AUBO i5 仿真

- [ ] 整理六轴关节名、轴向、零位、限位、速度和负载数据来源。
- [ ] 完成 inertial/collision 审查，`check_urdf` 通过。
- [ ] 创建 fake hardware + MoveIt 配置，执行 6 轴轨迹。
- [ ] 创建 Gazebo Sim 后端并验证控制器 active。
- [ ] 按低速测试计划验证桌面环境中的无碰撞轨迹。

## 第 5 周：AUBO 真机准备

- [ ] 与厂商确认驱动、协议、固件、接口权限和急停行为。
- [ ] 完成网络、只读状态、单轴低速、TCP/负载、坐标系验证。
- [ ] 演练拔网线、保护停和急停；确认能安全恢复。
- [ ] 首次执行只有经人工审查的低速短轨迹。

## 第 6–7 周：移动机器人仿真

- [ ] 将小车描述迁移为 Gazebo Sim 可用传感器与 `ros2_control` 接口。
- [ ] 实现 `cmd_vel -> wheel -> odom -> TF`。
- [ ] 加入 IMU/雷达，使用 EKF 得到稳定 `odom->base_link`。
- [ ] 用 slam_toolbox 建图，保存地图。
- [ ] 使用 AMCL + Nav2 连续完成 20 个导航目标。

## 第 8 周：移动机器人真机

- [ ] MCU 看门狗和硬件急停独立通过测试。
- [ ] 编码器、轮径、轮距、IMU 外参标定完成。
- [ ] 低速遥操作、建图、定位、导航逐级验收。
- [ ] 形成启动说明、故障手册、bag 回放用例和演示视频。

## 交付目录建议

```text
docs/                 # 本教程和设计决策
config/               # 可公开的示例参数
config/private/       # .gitignore：IP、标定结果、密钥
launch/               # simulation / real 显式分开
test/                 # 单元测试、launch test、bag 回放
bags/                 # .gitignore：原始实验数据
```
