# 实验 0：ROS 2 基础与现有控制代码复现

## 实验目标

在不修改代码的前提下，跑通仓库二维机械臂 RViz 闭环。完成后应能解释：为什么命令 topic 不会直接让 RViz 动起来、`/joint_states` 每个字段的作用，以及 `robot_state_publisher` 为什么必需。

## 知识点：节点、topic、消息与回调

ROS 2 的进程通常含一个或多个 node。node 由 DDS 自动发现，并在同名、同类型 topic 上传输消息。publisher 的 `publish()` 只是交给中间件；subscription callback 由 executor 调度。因此控制节点必须明确接收频率、队列深度和消息过期后如何停止。

仓库定义了 `JointVelocityCmd.msg`、`JointPositionCmd.msg` 和 `JointStateCommand.msg`。它们适合教学；与 MoveIt、控制器、真机连接时优先使用标准的 `sensor_msgs/JointState`、`trajectory_msgs/JointTrajectory`、`geometry_msgs/Twist` 和 `control_msgs/action/FollowJointTrajectory`。

## 知识点：joint_states、URDF 和 TF

`/joint_states` 的 `name[i]`、`position[i]`、`velocity[i]` 必须以同一索引表示同一个关节。`robot_state_publisher` 读取 URDF 的关节树，再用 `/joint_states` 做正运动学，发布 link 之间的动态 TF。RViz 显示的是 TF 中 link 的姿态，而不是命令 topic。固定关节来自 URDF，活动关节来自 `/joint_states`。

## 实验步骤

### 1. 构建与加载环境

```bash
cd ~/manipulator-control/robot_control_ros2
source /opt/ros/humble/setup.bash
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
```

### 2. 启动显示、状态和命令节点

终端 A：

```bash
source ~/manipulator-control/robot_control_ros2/install/setup.bash
ros2 launch simple_arm_description simple_2dof_arm_display.launch.py
```

终端 B：

```bash
source ~/manipulator-control/robot_control_ros2/install/setup.bash
ros2 run robot_control_ros2 joint_position_cmd_to_states
```

终端 C：

```bash
source ~/manipulator-control/robot_control_ros2/install/setup.bash
ros2 run robot_control_ros2 robot_position_cmd
```

预期数据流是：`robot_position_cmd -> /joint_position_cmd -> joint_position_cmd_to_states -> /joint_states -> robot_state_publisher -> TF -> RViz`。模型姿态应改变。

### 3. 用 CLI 观察证据

```bash
ros2 node list
ros2 topic list -t
ros2 topic echo /joint_position_cmd
ros2 topic echo /joint_states
ros2 topic hz /joint_states
ros2 topic info /joint_states -v
ros2 run tf2_tools view_frames
```

把两条 topic 输出并列比较：位置应被转发，`/joint_states.name` 必须与 URDF 关节名完全一致。`topic info -v` 能显示两端 QoS；QoS 不兼容会出现“能看到 topic 但收不到消息”。`view_frames` 生成 TF 图，一个 child 只能有一个 parent，且不能有环。

## 故障定位

1. 没模型：检查 RViz RobotModel 是否读到 `robot_description`。
2. 模型不动：`ros2 topic echo /joint_states --once`，检查 name、position 长度和关节名。
3. 有数据但报 TF：确认 `robot_state_publisher` 在运行，用 `view_frames` 找断链或重复发布。
4. 改代码没生效：重新 build 后重新 `source install/setup.bash`，避免被其他工作区 overlay 覆盖。
