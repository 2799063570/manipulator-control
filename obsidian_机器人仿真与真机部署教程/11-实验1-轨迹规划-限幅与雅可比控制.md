# 实验 1：轨迹规划、限幅与雅可比控制

## 实验目标

把 `robot_control` 从“能调用的 C++ 类”变成可解释的控制基础。依次验证状态、限幅、插值、队列和雅可比求解。最终要能说清：轨迹平滑不等于安全，数值可解不等于机器人可执行。

## 1. RobotState：控制系统的最小状态

关节状态通常由位置 q 和速度 dq 组成。当前 `RobotState(dof)` 用 vector 保存它们。工业系统还应包含 effort、时间戳、有效性、温度与故障码。所有数组接口都要检查 dof 和数组长度，否则会在高频循环中出现越界或关节错配。

```bash
cd ~/manipulator-control/robot_control_ros2
source install/setup.bash
ros2 run robot_control robot_state_test
```

如果可执行文件名不同，先运行 `find install/robot_control/lib -type f -executable`。阅读 `examples/robot_state_test.cpp`，增加并测试边界用例：0 自由度、数组长度不匹配、下标等于 dof、NaN/Inf 输入。真机接口必须拒绝非法数据，不能静默执行。

## 2. SafetyLimiter：限幅的意义与边界

`SafetyLimiter` 对每个关节将位置夹在 lower/upper limit 内，并把速度夹在最大速度内。修改 `safety_limiter_test.cpp`：构造 2 DOF，位置设为 `[4,-4]`，限制为 `[-3.14,3.14]`，速度设为大于最大值。重编译后，观察 clamp 前后的 q 和 dq。

```bash
colcon build --packages-select robot_control
source install/setup.bash
ros2 run robot_control safety_limiter_test
```

限幅仍不等于完整安全：它不知道碰撞、错误零位、通信断线、负载超标、急停和工作空间障碍，也通常不限制加速度/jerk。真机要叠加碰撞检测、命令超时、控制柜保护和实体急停。

## 3. 三次/五次插值实验

三次插值可同时满足起终点的位置与速度；五次插值还可以令起终点加速度为零，因此启动/停止更平滑。五次常用归一化形式为 `10*s^3 - 15*s^4 + 6*s^5`，其中 `s=t/T`。它只定义时间曲线，不自动满足碰撞、扭矩和峰值速度约束。

```bash
ros2 run robot_control cubic_interpolator_test
ros2 run robot_control control_loop_demo
```

将 demo 的 duration 分别改为 0.2 秒和 4 秒，记录相邻点差分 `(q[k+1]-q[k])/dt`。短 duration 会造成速度峰值明显增大；这说明必须进行速度/加速度约束的时间参数化。MoveIt 里的 TOTG 或 Ruckig 就承担这类工作。

## 4. TrajectoryBuffer：新命令如何抢占

轨迹生成端一次产生 N 个点，控制循环每周期 pop 一个点，是典型生产者—消费者模型。新命令到来有三种策略：

- 串行：旧轨迹结束后才执行，响应慢。
- 清空重规划：适合遥操作；新轨迹起点必须是当前反馈。
- 平滑抢占：从当前 q/dq 重新生成轨迹，速度连续，是工程推荐。

当前 `vel_to_pos_node.cpp` 的 buffer 可能保留旧轨迹。连续发布相反速度命令，观察是否先执行陈旧轨迹。学习性改进是在 callback 中清空 buffer，并以真实 `/joint_states` 更新 start state；最终建议迁移到可抢占 `FollowJointTrajectory` action，而不是自己维护所有边界情况。

## 5. 雅可比、伪逆与 DLS

雅可比满足“末端速度 = J(q) × 关节速度”。平面二连杆的位置由两个关节角决定，对关节角求导即可得到 2×2 雅可比。J 满秩且为方阵时可直接求逆；冗余、非方阵或奇异时用伪逆。接近奇异时最小奇异值很小，伪逆会放大噪声并给出很大的关节速度。

`JacobianSolver` 同时提供伪逆和阻尼最小二乘（DLS）。DLS 在求解中加入 lambda，使输出有界；lambda 越大，关节速度越小，但末端速度跟踪误差越大。

```bash
ros2 run robot_control jacobian_solver_test
```

实验：构造两行几乎线性相关的矩阵，分别用伪逆、lambda=0.01 和 lambda=0.1 求解，记录输出向量范数与 `conditionNumber()`。结论应是：条件数升高需要减速、增大阻尼或规划绕开该姿态，DLS 不能替代路径规划与关节限速。

## 6. 现有 Vel2PosNode 的工程缺口

它以速度指令推算目标位置，做五次插值后发布位置指令，适合理解控制链，但真机前必须：订阅真实状态；使用 ROS time/真实 dt；检查数组长度；避免高频日志；实现命令 timeout；处理新轨迹抢占；不把内部 goal 当作真实 current state。实际执行应交给 `JointTrajectoryController` 或 MoveIt Servo。
